PagePatch

Point at the page. Say what should change.

Open any webpage, click the text, image, link, list, or layout you want changed, and write the request right there. PagePatch keeps everything together in one file for the person who will build it.

Put PagePatch in your bookmarks

Drag this button to your bookmarks bar. Once it is there, click it to open PagePatch on any site.

Add the bookmark yourself

The code is copied. Paste it into a new bookmark.

  1. Show the bookmarks bar with Ctrl+Shift+B.
  2. Right-click the bar and choose Add page.
  3. Name it ✎ PagePatch by Evoltex.
  4. Paste the copied code into the URL field and save.
